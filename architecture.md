# Application Architecture

Quarterly Sales Insights & Region Variance Analyzer is a web-based sales analytics dashboard that helps business teams upload quarterly sales order CSV files—or explore a built-in global sample dataset—to compare revenue, unit volume, and discounting across regions and quarters. The application automatically aggregates raw order lines into interactive charts, a filterable regional pivot table, and an underlying order explorer, while pinpointing which geographic region experienced the largest dollar or percentage shift between Q2 and Q3. Using those verified calculations, a backend service generates a strictly grounded three-sentence executive summary explaining the revenue change and its primary product, volume, channel, and discount drivers, complete with an audit drawer so decision-makers can trace every figure back to the source data.

| File | Purpose |
| --- | --- |
| `.env.example` | Lists the environment configuration variables, such as the AI service key and web port, needed to run the application. |
| `.gitignore` | Tells version control which temporary, dependency, and secret files to exclude when saving project changes. |
| `architecture.md` | Provides a business-friendly overview of the application and a one-sentence guide to every file in the project. |
| `bun.lock` | Records exact package dependency versions generated by the container environment's package manager. |
| `index.html` | Defines the main web page shell, title, fonts, and layout container where the application loads in a browser. |
| `metadata.json` | Stores the application's display name, summary description, and server-side AI capability settings. |
| `package.json` | Lists the third-party software libraries and startup commands required to build and run the application. |
| `server.ts` | Runs the backend web server that serves the application and generates three-sentence AI executive summaries from calculated sales metrics. |
| `src/App.tsx` | Coordinates the overall dashboard layout by connecting uploaded sales data, channel and product filters, charts, tables, and the AI summary card. |
| `src/components/AISummaryCard.tsx` | Displays the three-sentence executive summary of Q2-to-Q3 regional performance alongside key metrics, region selectors, and a calculation audit breakdown. |
| `src/components/CsvUploader.tsx` | Provides a drag-and-drop and paste interface for importing sales order CSV files, validating columns, and previewing rows before loading. |
| `src/components/Header.tsx` | Renders the top navigation bar with portfolio totals and quick buttons to upload data, load sample orders, or download CSV templates. |
| `src/components/OrdersDrawer.tsx` | Opens a searchable, filterable, and paginated viewer so users can inspect individual sales order line items. |
| `src/components/RevenueChart.tsx` | Visualizes regional and quarterly revenue trends and Q2-to-Q3 dollar shifts through interactive bar and variance charts. |
| `src/components/RevenueTable.tsx` | Presents a sortable, filterable regional revenue and unit matrix with Q2-to-Q3 variance columns and CSV export. |
| `src/data/sampleDatasets.ts` | Supplies a built-in 71-order global sales dataset across four quarters and four regions along with downloadable CSV templates. |
| `src/index.css` | Loads the styling framework that controls colors, spacing, and typography across the dashboard. |
| `src/main.tsx` | Initializes and mounts the user interface into the browser web page. |
| `src/types/sales.ts` | Defines the shared data structures for sales orders, regional revenue matrices, and quarterly variance calculations. |
| `src/utils/calculations.ts` | Computes regional revenue matrices, Q2-to-Q3 dollar and percentage changes, unit shifts, discount averages, and top product and channel drivers. |
| `src/utils/csvParser.ts` | Reads uploaded CSV text, maps flexible column headers, cleans currency and percentage formatting, and converts rows into structured sales orders. |
| `tsconfig.json` | Configures TypeScript rules to check code accuracy and compatibility across the project. |
| `vite.config.ts` | Configures the frontend build and development server settings, including network host access and asset bundling. |
